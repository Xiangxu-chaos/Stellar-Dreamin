## 任务二：修复卡片尺寸与布局重叠

### 现象
除《杀戮尖塔》外，另外三个领域（王者荣耀 / 空洞骑士 / 无畏契约）卡片正面
「领域标签」与「英文单词」严重重叠，且卡片大小观感不统一。

### 根因
卡片 `.wordcard` 固定 `height: 336px`，正面 `.wordcard__face` 是 `flex column`
且 `overflow: hidden`。`.wordcard__figure` 原来是 `flex: none`（不可收缩），
长领域标签（`.chip` 原为 `white-space: nowrap`）把徽标行挤到 2~3 行后，正面内容
总高超过 302px 可用高度；`.wordcard__wordwrap` 虽 `flex: 1; min-height: 0`，
但被压到低于内容高度后，垂直居中的单词**上下双向溢出**，向上盖住徽标行 →
视觉重叠。（不是绝对定位导致的，正面本就是 flex column。）

### 修复（全部在 src/styles/components.css）
1. `.wordcard`：加 `min-height: 336px`（配合既有 height，四领域等高兜底）。
2. `.wordcard__figure`：`flex: none` → **`flex: 0 1 auto; min-height: 0`**，
   内容多时自动收缩，把空间让给单词区。
3. `.wordcard__badges`：加 `flex: none`（不被压缩，永远完整）。
4. `.wordcard__foot`：加 `flex: none`。
5. `.wordcard__wordwrap`：`flex: 1` → `flex: 1 1 auto` + **`overflow: hidden`**，
   空间不足时只在自身范围内裁切，绝不向上溢出与标签重叠。
6. `.chip` 基础类保持 `nowrap`；新增 `.wordcard__badges .chip--domain
   { white-space: normal; max-width: 100%; line-height: 1.35 }`——
   卡片里的长领域标签允许占两行，不横向溢出。
7. 顺带修复：编辑中误删的 `.chip--domain/--term/--derived/--core/.chip svg`
   与 `.flip__wordwrap` 选择符已完整还原。

### 测试
- 新增 `tools/verifyCardLayout.mjs`（41 断言）：静态校验 CSS（等高、正面 flex
  column、标签/单词非绝对定位、徽标&底部 flex:none、单词区 overflow:hidden、
  配图可收缩、长标签可换行）+ 动态为四领域各渲染一张卡片，断言正面节点顺序
  图→徽标→单词区→底部 且无绝对定位节点、背面例句区不受影响。
- 全量 **15 个脚本全部通过，0 失败**。

### 验收
- 四领域卡片等高（固定 336px + min-height）；正面标签在上、单词在下，
  纵向 flex 流式排版，绝不重叠；背面释义 / 例句排版未受影响。
