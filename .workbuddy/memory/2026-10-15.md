## 追加：修复「收藏夹翻面镜像」（CSS 3D 翻转被拍平）

**现象**：收藏夹（以及所有用 `createWordCard` 的卡片）翻转后，背面文字左右反转（镜像）。

**根因**：`.wordcard` / `.flip` 的入场动画 `card-in` 用了 `animation-fill-mode: both`，
动画结束后元素**持久保留 `transform: scale(1)`**（to 帧）。这两个父级**没有**
`transform-style: preserve-3d`，于是残留 transform 把子级 `.wordcard__inner` 的
`rotateY(180deg)` **拍平成 scaleX(-1)** → 背面镜像。收藏夹翻面最频繁，所以最显眼。

**修复**（`src/styles/components.css`，`.wordcard` 与 `.flip` 两处同改）：
1. `animation` 收尾由 `both` 改为 `backwards`（to 帧即自然态，不持久化 transform）；
2. 两父级加 `transform-style: preserve-3d`（即使入场动画期间也不拍平 3D 上下文）。

入场动画视觉不变（to 帧 = 自然态）。预览 8123 已起。

⚠️ **教训（写进 MEMORY 长期规则）**：凡做 3D 翻转卡，翻转父级务必 `preserve-3d`，
且绝不能在翻转父级上持久化非 `none` 的 transform，否则子级 rotateY 会被拍平成镜像。

## 追加：两处修正（用户二次反馈）

### 1. 翻面镜像的真正根因是「熟词」+ filter

上一轮的 `both→backwards` + `.wordcard` 加 `preserve-3d` 只修了「入场动画残留 transform 拍平」
这一条，但**熟词翻面仍镜像**。真凶是：
`.wordcard.is-mastered .wordcard__inner { filter: saturate(0.5) brightness(0.94); }`
—— `filter` 会强制 `transform-style: flat`，把子级两张 face 的 `rotateY(180deg)` 拍平成
`scaleX(-1)` → 背面镜像。
**修法**：把 `filter` 从 `.wordcard__inner` 移到 leaf 级的 `.wordcard__face`（前/后两面都加），
面部自身 rotateY 不受影响、也不会拍平翻转上下文。视觉弱化效果不变。

### 2. 做题排除熟词库单词

需求：所有做题模式（领域测验 / 收藏夹复习 / 错题复习 / 分组复习）都不再出「已掌握」的单词。
所有入口最终都走 `quizService.getQuestionPool()`，故在该函数统一拦截：
- 取 `dataService.getMasteredKeys()`（domainId::word 集合）；
- 三个分支（FAVORITES / ALL / DOMAIN）返回的题池都 `.filter` 掉已掌握词；
- 干扰项后备全库池（`getDistractorPool`）同样排除熟词，避免熟词作为选项出现。
键格式与 dataService 的 `cardKey` 一致（`${d}::${String(word).toLowerCase()}`）。

**修改文件**：`src/styles/components.css`（is-mastered filter 移位）、
`src/services/quizService.js`（getQuestionPool + getDistractorPool 加熟词过滤）。

## 追加：「核心 / 相关 / 泛化」三档机制 + 选择器数字 + 复习按档过滤 + 卡片档位标签

### 一、档位怎么算（核心设计）

**不按数据来源分档**（专有术语 / 领域词 / 场景泛化），而是按 `filterByDomain` 的
**召回分数排名**分档：核心＝前 20%，相关＝20–50%，泛化＝50–100%；
少于 20 个词的领域**统一归核心**（避免切档后没词可做）。
分档在 `computeDomainWords()` 建缓存时**一次算完**（`assignTiers()`），
挂在词条对象的 `tier` 字段上，随缓存复用 —— **不额外增加遍历**。

⚠️ **关键坑**：`filterByDomain` 的 `limit` 是在排序后切片的，所以
**分档必须基于完整列表**再切片（否则 1418 词的领域按前 600 词算百分位，分档全错）。
本实现把 `assignTiers()` 放在 `computeDomainWords` 的排序之后、切片之前。
